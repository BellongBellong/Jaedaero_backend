# 성능 테스트 결과

## 환경

- 로컬 Docker: Tomcat, MySQL, Prometheus, Grafana
- 도구: k6
- CODEF 실연동 API는 제외

## 적용한 개선

- 챌린지 그룹 랭킹 결과를 10초간 캐시
- 미션 완료 시 뱃지 ID를 정렬해 잠금 순서를 통일
- MySQL 데드락 발생 시 독립 트랜잭션으로 최대 5회 재시도
- k6 미션 쓰기 시나리오가 전역 반복 번호로 테스트 사용자를 배정하도록 수정

## 결론

캐시 적용으로 챌린지 랭킹 조회 병목을 해소했고, 대시보드 조회와 혼합 사용자 흐름은 100 VU에서 실패 없이 안정적으로 처리됐다. 미션 완료는 50 VU에서 실패율 0%를 달성했으며, 100 VU에서도 1건의 503만 발생해 1% 기준을 통과했다.
